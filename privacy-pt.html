Política de Privacidade

Prism Rows não usa contas de usuário, publicidade ou análises. O progresso e as configurações ficam armazenados localmente no seu dispositivo.

Desenvolvedor e escopo

Esta Política de Privacidade se aplica ao Prism Rows, publicado pela TraditionalDimension.

Coleta de dados

Prism Rows não coleta, transmite, vende nem compartilha pelo jogo dados pessoais ou sensíveis do usuário. O jogo não usa publicidade, análises, contas de usuário ou compras no aplicativo.

Dados armazenados no dispositivo

O progresso, as conquistas, o estado da partida e as configurações são salvos localmente para que Prism Rows possa lembrá-los. A TraditionalDimension não recebe essas informações do jogo.

Retenção e exclusão

Prism Rows não mantém uma cópia do seu progresso em servidor. Os dados locais do jogo podem ser removidos pelos controles de dados do aplicativo no seu dispositivo. A TraditionalDimension não pode recuperar nem excluir remotamente dados que o jogo nunca nos envia.

Tratamento de dados

Como Prism Rows não transmite dados pessoais ou sensíveis para a TraditionalDimension, o desenvolvedor não mantém armazenamento de dados de jogadores em servidor para o jogo.

Sites externos

Prism Rows pode abrir sites externos somente depois que você escolher um link. GitHub, Boosty, lojas de aplicativos e outros serviços externos operam de forma independente e podem ter suas próprias políticas de privacidade.

Dúvidas sobre privacidade

Dúvidas sobre esta política podem ser enviadas pela página de GitHub Issues do Prism Rows. GitHub Issues é público, então não inclua informações pessoais ou sensíveis no relato.

Alterações nesta política

Se a forma como Prism Rows lida com dados mudar, esta página será atualizada.
