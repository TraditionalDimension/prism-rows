## Android closed test

Prism Rows is currently available through a Google Play closed test.

### How to join

1. Join the official Google Group:
   https://groups.google.com/g/prism-rows-closed-testers

2. Use the same Google account in Google Play.

3. Opt in to the closed test:
   https://play.google.com/apps/testing/com.traddim.prismrows

4. On your Android device, open:
   https://play.google.com/store/apps/details?id=com.traddim.prismrows

5. Install Prism Rows and test the current build.

6. Send bug reports and feedback through:
   https://github.com/TraditionalDimension/prism-rows/issues

Google Group email:

`prism-rows-closed-testers@googlegroups.com`

The site is available in the same nine languages as the game: English, Deutsch, Français, Polski, Русский, 中文, Türkçe, Español, and Português.
