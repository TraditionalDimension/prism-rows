Support

Prism Rows is a free, ad-free puzzle game by TraditionalDimension.

If you found a bug, please include the game version, device model, Android version, what you did before the problem, and a screenshot if possible.

Email: adkl2011@gmail.com

Useful first steps

  • Restart the game and check whether the issue repeats.
  • Do not clear app storage before saving screenshots or the QA report.
  • For progress issues, mention whether the game was updated or reinstalled.
