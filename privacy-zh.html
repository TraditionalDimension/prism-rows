隐私政策

Prism Rows 不使用用户账号、广告或分析工具。游戏进度和设置保存在你的设备本地。

开发者与适用范围

本隐私政策适用于由 TraditionalDimension 发布的 Prism Rows。

数据收集

Prism Rows 不会通过游戏收集、传输、出售或共享个人或敏感用户数据。游戏不使用广告、分析工具、用户账号或应用内购买。

设备上的数据

游戏进度、成就、挑战状态和设置保存在本地，以便 Prism Rows 记住这些内容。TraditionalDimension 不会从游戏中收到这些信息。

保留与删除

Prism Rows 不会在服务器端保存你的游戏进度副本。你可以通过设备的应用数据设置删除本地游戏数据。对于游戏从未发送给我们的数据，TraditionalDimension 无法远程读取或删除。

数据处理

由于 Prism Rows 不会向 TraditionalDimension 传输个人或敏感用户数据，开发者不会为本游戏运营服务器端玩家数据存储。

外部网站

只有在你主动选择链接后，Prism Rows 才可能打开外部网站。GitHub、Boosty、应用商店及其他外部服务独立运行，并可能有各自的隐私政策。

隐私问题

关于本政策的问题可通过 Prism Rows 的 GitHub Issues 页面提交。GitHub Issues 是公开的，请不要在报告中包含个人或敏感信息。

政策变更

如果 Prism Rows 处理数据的方式发生变化，本页面将随之更新。
