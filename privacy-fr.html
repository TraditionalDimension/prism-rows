Politique de confidentialité

Prism Rows n’utilise ni compte utilisateur, ni publicité, ni outil d’analyse. La progression et les paramètres restent stockés localement sur votre appareil.

Développeur et portée

Cette Politique de confidentialité s’applique à Prism Rows, publié par TraditionalDimension.

Collecte des données

Prism Rows ne collecte, ne transmet, ne vend et ne partage aucune donnée personnelle ou sensible via le jeu. Le jeu n’utilise ni publicité, ni analyse, ni compte utilisateur, ni achat intégré.

Données stockées sur l’appareil

La progression, les succès, l’état de la partie et les paramètres sont enregistrés localement afin que Prism Rows puisse les conserver. TraditionalDimension ne reçoit pas ces informations du jeu.

Conservation et suppression

Prism Rows ne conserve aucune copie de votre progression sur un serveur. Les données locales du jeu peuvent être supprimées via les réglages de données de l’application sur votre appareil. TraditionalDimension ne peut ni récupérer ni supprimer à distance des données que le jeu ne nous envoie jamais.

Traitement des données

Comme Prism Rows ne transmet aucune donnée personnelle ou sensible à TraditionalDimension, le développeur n’exploite aucun stockage serveur de données de joueurs pour le jeu.

Sites externes

Prism Rows peut ouvrir un site externe uniquement après que vous avez choisi un lien. GitHub, Boosty, les boutiques d’applications et les autres services externes fonctionnent indépendamment et peuvent avoir leurs propres politiques de confidentialité.

Questions sur la confidentialité

Les questions concernant cette politique peuvent être envoyées via la page GitHub Issues de Prism Rows. Les Issues GitHub sont publiques : n’y publiez aucune information personnelle ou sensible.

Modifications de cette politique

Si la manière dont Prism Rows traite les données change, cette page sera mise à jour.
