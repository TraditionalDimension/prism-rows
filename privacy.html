Privacy Policy

Prism Rows does not use user accounts, advertising, or analytics. Game progress and settings are kept locally on your device.

Developer and scope

This Privacy Policy applies to Prism Rows, published by TraditionalDimension.

Data collection

Prism Rows does not collect, transmit, sell, or share personal or sensitive user data through the game. The game does not use advertising, analytics, user accounts, or in-app purchases.

Data stored on your device

Game progress, achievements, run state, and settings are stored locally so Prism Rows can remember them. TraditionalDimension does not receive this information from the game.

Retention and deletion

Prism Rows does not keep a server-side copy of your game progress. Local game data can be removed through your device’s application-data controls. TraditionalDimension cannot remotely retrieve or delete data that the game never sends to us.

Data handling

Because Prism Rows does not transmit personal or sensitive user data to TraditionalDimension, the developer does not operate a server-side store of player data for the game.

External websites

Prism Rows may open external websites only after you choose a link. GitHub, Boosty, app stores, and other external services operate independently and may have their own privacy policies.

Privacy questions

Questions about this policy can be submitted through the Prism Rows GitHub Issues page. GitHub Issues are public, so do not include personal or sensitive information in a report.

Changes to this policy

If the way Prism Rows handles data changes, this page will be updated.
