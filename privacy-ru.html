Политика конфиденциальности

В Prism Rows нет пользовательских аккаунтов, рекламы и аналитики. Прогресс и настройки хранятся локально на вашем устройстве.

Разработчик и область действия

Эта Политика конфиденциальности относится к Prism Rows, опубликованной TraditionalDimension.

Сбор данных

Prism Rows не собирает, не передаёт, не продаёт и не распространяет через игру персональные или чувствительные данные пользователей. В игре нет рекламы, аналитики, пользовательских аккаунтов и встроенных покупок.

Данные на устройстве

Прогресс, достижения, состояние забега и настройки хранятся локально, чтобы Prism Rows могла их запомнить. TraditionalDimension не получает эти данные от игры.

Хранение и удаление

Prism Rows не хранит серверную копию игрового прогресса. Локальные данные игры можно удалить через настройки данных приложения на вашем устройстве. TraditionalDimension не может удалённо получить или удалить данные, которые игра нам не отправляет.

Обработка данных

Поскольку Prism Rows не передаёт TraditionalDimension персональные или чувствительные данные пользователей, разработчик не ведёт серверное хранилище данных игроков для этой игры.

Внешние сайты

Prism Rows может открыть внешний сайт только после того, как вы сами выберете соответствующую ссылку. GitHub, Boosty, магазины приложений и другие внешние сервисы работают независимо и могут иметь собственные политики конфиденциальности.

Вопросы о конфиденциальности

Вопрос по этой политике можно задать через GitHub Issues Prism Rows. Issues на GitHub публичны, поэтому не указывайте в обращении персональные или чувствительные данные.

Изменения политики

Если способ работы Prism Rows с данными изменится, эта страница будет обновлена.
