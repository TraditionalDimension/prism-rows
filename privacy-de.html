Datenschutzerklärung

Prism Rows verwendet keine Benutzerkonten, Werbung oder Analysen. Spielfortschritt und Einstellungen bleiben lokal auf deinem Gerät.

Entwickler und Geltungsbereich

Diese Datenschutzerklärung gilt für Prism Rows, veröffentlicht von TraditionalDimension.

Datenerhebung

Prism Rows erhebt, überträgt, verkauft oder teilt über das Spiel keine personenbezogenen oder sensiblen Nutzerdaten. Das Spiel verwendet keine Werbung, Analysen, Benutzerkonten oder In-App-Käufe.

Daten auf deinem Gerät

Spielfortschritt, Erfolge, Laufstatus und Einstellungen werden lokal gespeichert, damit Prism Rows sie beibehalten kann. TraditionalDimension erhält diese Informationen nicht vom Spiel.

Speicherung und Löschung

Prism Rows speichert keine serverseitige Kopie deines Spielfortschritts. Lokale Spieldaten können über die App-Dateneinstellungen deines Geräts entfernt werden. TraditionalDimension kann Daten, die das Spiel nie an uns sendet, weder aus der Ferne abrufen noch löschen.

Datenverarbeitung

Da Prism Rows keine personenbezogenen oder sensiblen Nutzerdaten an TraditionalDimension überträgt, betreibt der Entwickler für das Spiel keinen serverseitigen Speicher für Spielerdaten.

Externe Websites

Prism Rows öffnet externe Websites nur, nachdem du einen entsprechenden Link ausgewählt hast. GitHub, Boosty, App-Stores und andere externe Dienste arbeiten unabhängig und können eigene Datenschutzerklärungen haben.

Fragen zum Datenschutz

Fragen zu dieser Erklärung können über die GitHub-Issues-Seite von Prism Rows gestellt werden. GitHub Issues sind öffentlich; gib dort daher keine personenbezogenen oder sensiblen Informationen an.

Änderungen dieser Erklärung

Wenn sich die Datenverarbeitung von Prism Rows ändert, wird diese Seite aktualisiert.
