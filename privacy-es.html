Política de privacidad

Prism Rows no utiliza cuentas de usuario, publicidad ni analítica. El progreso y los ajustes se guardan localmente en tu dispositivo.

Desarrollador y alcance

Esta Política de privacidad se aplica a Prism Rows, publicado por TraditionalDimension.

Recopilación de datos

Prism Rows no recopila, transmite, vende ni comparte a través del juego datos personales o sensibles del usuario. El juego no utiliza publicidad, analítica, cuentas de usuario ni compras dentro de la aplicación.

Datos almacenados en el dispositivo

El progreso, los logros, el estado de la partida y los ajustes se guardan localmente para que Prism Rows pueda recordarlos. TraditionalDimension no recibe esta información del juego.

Conservación y eliminación

Prism Rows no guarda una copia de tu progreso en un servidor. Los datos locales del juego pueden eliminarse desde los controles de datos de la aplicación de tu dispositivo. TraditionalDimension no puede recuperar ni borrar de forma remota datos que el juego nunca nos envía.

Tratamiento de datos

Como Prism Rows no transmite datos personales o sensibles a TraditionalDimension, el desarrollador no mantiene un almacenamiento de datos de jugadores en servidores para el juego.

Sitios externos

Prism Rows puede abrir sitios externos únicamente después de que elijas un enlace. GitHub, Boosty, las tiendas de aplicaciones y otros servicios externos funcionan de forma independiente y pueden tener sus propias políticas de privacidad.

Preguntas sobre privacidad

Las preguntas sobre esta política pueden enviarse mediante la página de GitHub Issues de Prism Rows. GitHub Issues es público, así que no incluyas información personal o sensible en el informe.

Cambios en esta política

Si cambia la forma en que Prism Rows trata los datos, esta página se actualizará.
